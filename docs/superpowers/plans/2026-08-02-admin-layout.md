# 企业级后台基础布局实现计划

**目标：** 在现有 Vue3 认证基础上接入 Element Plus，实现登录后可切换的企业后台框架。

**范围：** 新增四个纯展示视图、固定侧栏、顶部用户栏和路由；不调用任何业务接口，不修改 FastAPI。

1. 先增加路由测试，要求存在驾驶舱、数据集、AI 分析与下载中心四条受保护路由。
2. 安装 Element Plus，在 `main.js` 注册组件库；重构 `App.vue` 为登录页与后台布局的条件入口。
3. 扩展 `router/index.js`，新增四个视图路由，保留已有登录鉴权逻辑。
4. 新建四个 View 文件，仅提供标题、说明和空状态框架。
5. 执行 Vitest、Vite 构建，并在浏览器验证菜单切换和退出登录。
